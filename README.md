# 신지영 개발자 포트폴리오

## 확인 및 실행
압축을 풀고 최상위 index.html을 브라우저에서 엽니다. 설치·빌드·API 키는 필요하지 않습니다.
페이지 본문과 증명사진은 외부 연결 없이 열 수 있습니다. GitHub·Notion 링크를 열 때는 인터넷 연결이 필요합니다.

## GitHub Pages 배포
1. ZIP의 압축을 풉니다.
2. index.html, style.css, script.js, assets 폴더, .nojekyll을 저장소 최상위에 업로드합니다. ZIP 파일 자체를 업로드하지 않습니다.
3. 저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다.
4. 배포가 완료되면 Pages에 표시되는 주소를 확인합니다.
5. 공개된 주소에서 사진, 메뉴, 프로젝트 기록, Gmail 연락처 링크를 확인한 후 지원서에 사용합니다.

## 반영 사항
파랑·흰색 디자인 / 증명사진 / 간결한 카테고리 / MeetUpLog 우선 / 상단 노션 버튼 / 자격증 최신순 / Gmail 주소.
첨부 이력서 기준으로 MeetUpLog 4인 팀·기간·저장소, 학과명과 K-Shield 이력을 보완했습니다.
Spring Boot·JPA 및 MyBatis 실습을 팀 프로젝트와 구분하여 추가했습니다.
개인 기여만 설명하고, 팀 프로젝트 전체를 단독 개발로 표현하지 않았습니다.

## 파일
index.html / style.css / script.js / assets/shin-jiyoung.jpg / assets/favicon.svg / .nojekyll
CONTENT_SOURCES.md: 문구 출처와 점검 시 결정 사항.
VERIFICATION.json: 수행한 검사 및 검증 범위.

## 검증 범위
파일 참조, 내부 메뉴, HTML 접근성 기초 구조, 사진 디코딩, JavaScript 문법, CSS 구조, ZIP 무결성을 검사했습니다.
미리보기 서버 접속이 실패하고 로컬 파일 브라우저 접근이 정책상 제한되어 실제 PC·모바일 시각 검증은 완료하지 못했습니다.
프로젝트 화면 원본 파일은 다운로드 오류로 포함하지 못해 Notion 구현 기록 링크로 연결합니다.
증명사진은 기존에 확보한 동일 사진의 332×425 JPG 원본입니다. 새 고해상도 PNG 파일은 반영하지 못했습니다.
